# Design System

## Direction

Cinematic technical: dark base, bright spatial imagery, precise typography,
clean cards and restrained motion.

## Visual Priorities

1. UAV / 3D visuals
2. Orthomosaics and DEMs
3. GIS maps
4. Remote sensing outputs
5. Technical diagrams and platform screenshots

## UI Patterns

- Large hero visuals.
- Area cards with image backgrounds.
- Project cards with keyword chips.
- Inline `Read more` accordion.
- Lightbox galleries.
- Sticky top navigation.

## Typography

- Sans-serif for interface and body text.
- Large display headings.
- Short paragraphs and scannable metadata.

## Motion

Use subtle reveal and hover effects. Avoid heavy scroll hijacking or animation
that blocks reading.
